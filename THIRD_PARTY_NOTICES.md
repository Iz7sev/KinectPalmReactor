# Third-party dependencies

The public archive contains the Unity project source and tests. Dependency binaries are obtained from their original publishers by Setup-Dependencies.ps1.

| Component | Publisher / source |
|---|---|
| Azure Kinect Sensor SDK 1.4.2 / k4a / depth engine | https://github.com/microsoft/Azure-Kinect-Sensor-SDK ; review the installed SDK LICENSE.txt and depth engine terms |
| MediaPipe Unity Plugin 0.16.3 | https://github.com/homuler/MediaPipeUnityPlugin ; MIT and bundled third-party notices |
| Hand Landmarker model | https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker ; publisher model terms |
| System.Buffers / System.Memory / System.Runtime.CompilerServices.Unsafe / System.Reflection.Emit.Lightweight | Microsoft NuGet packages; package license metadata/files |
| Unity | https://unity.com/legal ; installed separately |

The current hand/palm input uses MediaPipe and Azure Kinect Sensor SDK. The Body Tracking runtime and its ONNX model from earlier experiments are not needed by the current code and are not distributed in this archive.
Drone graphics, UI effects and simple audio tones are generated by the project code. No Marvel character art, logos or other franchise assets are bundled.
